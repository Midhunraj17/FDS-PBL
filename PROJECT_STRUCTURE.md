# Project Structure

- `preprocessing/`: loading, validation, splitting, scaling, masking, windowing and graph construction.
- `models/`: GCN, GRU baseline, GCN-GRU and losses.
- `training/`: training and checkpoint utilities.
- `evaluation/`: forecasting, imputation and model comparison metrics.
- `congestion/`: congestion detection and network propagation analysis.
- `visualization/`: EDA, network, missingness and congestion figures.
- `app/`: Streamlit dashboard.
- `scripts/`: executable preparation, EDA, training and evaluation entry points.
- `tests/`: unit and synthetic integration tests.
- `outputs/`: generated artifacts, metrics, plots, predictions and checkpoints.
