# TrafficScope-AI

TrafficScope-AI is a deployable college-level Data Science and Machine Learning prototype for missingness-aware traffic forecasting, traffic-state reconstruction, and network-based congestion analysis.

## Core workflow

PEMS04 → validation → EDA → chronological split → normalization → simulated missingness → missingness mask → traffic graph → GRU baseline + GCN-GRU → imputation + forecasting → MAE/RMSE/MAPE → congestion analysis → Streamlit dashboard.

## Dataset

The supplied implementation uses **PEMS04**, a multivariate California PeMS benchmark with 16,992 time steps, 307 sensors and 3 traffic features. The repository layout expects `data/raw/PEMS04/PEMS04.npz` and `PEMS04.csv`.

## Installation

Python 3.10+ is recommended.

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# Linux/macOS
source .venv/bin/activate
pip install -r requirements.txt
```

## Run the complete pipeline

```bash
python run.py
```

The pipeline prepares data, generates EDA figures, trains the GCN-GRU model, evaluates it, and creates analysis artifacts.

## Models

- Persistence baseline
- Temporal GRU baseline
- Missingness-aware GCN-GRU multi-task model

The GCN learns spatial relationships from the PEMS04 sensor graph. The GRU models temporal evolution. The final model has forecasting and historical imputation heads.

## Scientific integrity

All reported metrics are generated by actual execution. No accuracy, MAE, RMSE, MAPE, improvement percentage, demand ground truth, or congestion-propagation accuracy is hard-coded.

## Limitations

PEMS04 is a benchmark dataset; simulated missingness does not perfectly represent real sensor failures; congestion is inferred from a configurable speed threshold; propagation analysis is network-based rather than causal; demand analytics are a proxy rather than OD demand estimation.
